# linkctl 1.0.0

`linkctl` 1.0.0 freezes machine-output schema 1 and local daemon protocol 1. The standard package includes direct and
daemon-owned camera control, capture and recording, PipeWire/ALSA audio, transactional presets, verified camera-native
Link 2C Pro controls, diagnostics, safe research reads, and the official manual firmware-staging workflow.

Release artifacts include native Debian, Fedora/RPM, Arch, and Arch Linux ARM packages, the pinned NixOS flake, a
deterministic source archive, CycloneDX SBOMs, `release-manifest.json`, checksums, and GitHub artifact attestations.

Physical-camera release validation includes a 30-minute 4K30 H.264 pass-through run, a one-hour 1080p60 H.264 plus
48 kHz mono FLAC run with sub-frame measured A/V drift, restart-dependent low-resolution and native-portrait capture,
and tuple-preserving daemon snapshot and recording recovery across unplug/replug.

Important boundaries:

- Writable vendor controls require the compiled-in profile for the exact recorded Link 2C Pro firmware and descriptor.
- Host vision/effects, multi-camera daemon supervision, remote control, and logical privacy transitions are unavailable.
- Virtual-output graph production is implemented, but OBS and WebRTC are unsupported with tested v4l2loopback 0.15.4.
- No firmware image is bundled, downloaded, or staged automatically.
